# Warehouse Slotting AI

> Place every SKU where it picks fastest

Optimizes warehouse slotting using order history, SKU affinity and seasonality to cut pick travel time and congestion.

**Live:** https://ziontechgroup.com/warehouse-slotting-ai/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- ABC/velocity analysis with golden-zone placement
- SKU affinity clustering for batch picking
- Seasonal re-slotting plans with move-cost estimates
- Heatmaps of picker travel and congestion
